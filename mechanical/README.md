## 2. 打印建议

| 参数 | 建议值 |
| --- | --- |
| 材料 | PLA（够用）或 PETG（更韧、耐摔） |
| 层高 | 0.2 mm |
| 填充 | 20%~30%（腿件可 40%，脚掌 20%） |
| 壁厚 | 3 层墙 |
| 支撑 | 悬空处需要，注意别把舵机安装孔堵了 |

## 3. 150 mm 尺寸校核（比赛要求）

规则是**静置状态**长宽高均 ≤ 150 mm。机身 75×66 本身没问题，风险在四条腿外伸：

| 方向 | 机身尺寸 | 允许外伸 |
| --- | --- | --- |
| 左右（宽） | 66 mm | 每侧 ≤ 42 mm |
| 前后（长） | 75 mm | 每端 ≤ 37.5 mm |
| 高度 | 10 mm（板） | 站立总高 ≤ 150 mm |

**装配完成后请用卡尺实测一次总长宽并拍照留证。** 若超尺寸，检录时把腿收拢成趴伏姿态再量。

## 4. 装配注意

- 舵机先中立（90°）再装舵盘，否则膝关节会有一侧行程不够。
- 膝关节的初始角度左右不对称（76/95/80/100），这是**打印公差 + 舵机齿位误差**的补偿，别强行设成 90°。
- PCB 是 50×80 mm，比机身长边还长 5 mm，装机时注意探出部分别顶到舵机臂，必要时加高铜柱。
